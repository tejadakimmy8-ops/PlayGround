# Plan: Landscape-First Refactor (Step 1) — Tiny Tindahan

## Goal
Reorganize `index.html` into a landscape-first presentation (wide split-panel composition, dismissible rotate hint, 2.5D/isometric canvas on a 2:1 tile grid with behind-the-counter shop view) **without** changing game logic, save schema, customization, or catalog systems.

## Non-goals / constraints
- No edits to save schema (`KEY=tinyTindahan_v1`), `defState/load/save/migration`, coins/pricing/balance, ad/delivery rules, audio, or story content.
- No ID renames, no handler-signature changes; all render functions keep writing the same DOM.
- No `screen.orientation.lock()`; portrait must stay fully playable (overlay is a dismissible hint, session-only).
- Touch targets ≥44px, safe-area insets, popups fit ~360px height with internal scroll, reduced-motion preserved.

## Baseline (verified read-only, 2026-10-10)
- `index.html`, 837 lines, single inline `<script>`; portrait column `#wrap{max-width:480px}`.
- Canvas `480×360` side-view scene; `scene()→update(dt)→rAF`; no resize/orientation listeners; zero landscape/media-query rules (only `prefers-reduced-motion`).
- Preserve: `S.char{name,gender,outfit,skin,hair,hs,cloth,body}`, `OUTFITS` ids `b_s1..b_l2/g_s1..g_l2`, `SKINS/HAIRS/HSTYLES/CLOTHES90/CLOTHESNEW`, `buildCharOpts/selectOutfit/setGender/syncName/outfitLabel`, `AVATAR_SVG`+canvas fallback, `PRODUCTS` (22), shelf/tray/serve flow, delivery/ads, upgrades/eras, all element IDs and tab-switching logic.
- `ctx.roundRect` used for nameplates (2×) — needs a guard for older WebViews.

## Changes

### 1. HTML — 2 new nodes only
- `#rotateTip` (first child of `body`): `🔄 Paik Gut: mas malapad ang laro sa landscape` + `#rotateOk` button. ~5 lines JS: click adds `.hide` (session-only, resets on reload).
- `#sideCol` wrapper around existing `#orderPanel + #shelf + 4 sheets` (pure DOM move, no content edits).

### 2. CSS — one landscape block + safe areas
- `@media (orientation:landscape) and (min-aspect-ratio:13/10)` (aspect gate keeps narrow iframes on portrait layout):
  - `#wrap{max-width:1060px}` → grid `top / stage+side / stage+tabs`; `#stage` left (flex-centered, `canvas{object-fit:contain}`); `#sideCol` right column; `#tabs` static bottom-right.
  - Short-height caps: `#sheetWrap{flex:1;overflow:auto}`, `.sheet{height:100%}`, `#shelf{repeat(4,1fr);max-height:30dvh;overflow:auto}`, `#orderPanel{max-height:32dvh;overflow:auto}`, `.box{max-height:86dvh;width:min(560px,92vw)}`.
  - `#rotateTip` shown only in portrait (`max-aspect-ratio:1/1`), `position:sticky` (never fixed/modal).
- Safe areas: `env(safe-area-inset-*)` on `#wrap/#topbar/#tabs/#toast`. Portrait rules byte-identical behavior.

### 3. Canvas — isometric projection, logic untouched
- Buffer `480×360` → `640×360`; replace `W=480,H=360` with `cv.width/cv.height`; audit hardcoded `480/510/±30` → `W`-relative.
- Add `worldToScreen()` helper (`TW=64,TH=32`, origin tuned to center diamond); `update()/queue/spawn/showOrder/serve` operate in world units unchanged — only draw calls remap.
- Re-anchor 8 draw blocks to tiles (painter's order, sorted by `wx+wy`): diamond ground/road strip, back-row house parcels (same kubo/concrete branches), store+radio parcel, corner trees/edge fence segments, foreground counter diamond (canopy/sign/jars/packets reused along counter lip, `slice(0,10)` unchanged), vendor **behind** counter south side, customers across counter on far side, `flyItems` arc counter→customer, nameplates same pill style.
- Reuse `drawPerson/drawPacket/drawBottle` unchanged (billboards); keep `sway()`/`S.reduced` gating.
- `ctx.roundRect` 6-line fallback guard.
